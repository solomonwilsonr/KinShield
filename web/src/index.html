KinModelOur own tiny scam model, published with every caveat

KinModel is a small classifier we trained ourselves: TF-IDF plus logistic regression, 119 KB of int8 weights, scored in pure Python inside AWS Lambda.

It runs inside KinBot, where it gives a fast, cheap second opinion next to the cited Bedrock check (KinVoice doesn't use it yet). It is not an LLM, and it is labelled experimental everywhere.

Honest notes

What KinShield is, and isn't

lock

Your message isn’t kept

Messages are checked and forgotten. If you choose to sign in, only each check’s verdict, headline and date are saved, never the message. The call demo keeps only per-session risk events.

verified_user

It can be wrong

A LOW result doesn't prove something is safe. If money is involved, call back on a number you already trust.

memory

Stock model in the app

The live detector is gpt-oss-20b on Amazon Bedrock with a structured prompt. We also fine-tuned gpt-oss-20b as research (results), but the app doesn't use it yet.

science

Pre-launch

Everything here is a working demo live on AWS. Nothing is for sale and there are no paying customers yet.

Under the hood

How it runs on AWS

  1. Browser
  2. Amazon API Gateway
  3. AWS Lambda
  4. Amazon Bedrock

On Bedrock, gpt-oss-20b runs the evidence detector and the link-investigator agent, Qwen3-VL reads screenshots, and Mistral Voxtral transcribes voicemails. Amazon Polly voices the demo calls, Amazon DynamoDB keeps per-session risk events, and sign-in through Amazon Cognito is optional.
